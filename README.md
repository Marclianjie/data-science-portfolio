# Data science portfolio — Lianjie (Marc) Shi

Statistics and machine learning projects from my work at the University of British Columbia and Peking University. Each folder has a short write-up, a figure of the main result, and the code or report.

Website: [marclianjie.github.io](https://marclianjie.github.io)

| Project | Course | Methods |
|---|---|---|
| [Bayesian models for day-to-day emotion dynamics](bayesian-emotion-dynamics) | STAT 405 Bayesian Statistics, UBC (2026) | Stan, ordered-logistic latent models, HMC vs. variational inference, PSIS-LOO |
| [What helps a small CNN generalize?](cnn-ablation-dogs-vs-cats) | Deep Learning & AI, PKU (2026) | PyTorch, 2 × 2 ablation of BatchNorm and data augmentation |
| [A leakage-free model comparison for brand choice](oj-brand-choice) | Machine Learning & AI, PKU (2026) | scikit-learn pipelines, stratified CV, temporal validation, permutation importance |
| [Deep learning from first principles](deep-learning-foundations) | Deep Learning & AI, PKU (2026) | Gradient descent vs. OLS simulation, autograd, Adam, MLP, CNN |
| [Forecasting daily temperature in Delhi](delhi-temperature-forecasting) | STAT 443 Time Series, UBC (2026) | Exponential smoothing, ARIMA, regression with ARMA errors |
| [A 2³ factorial experiment on coffee acidity](coffee-acidity-factorial) | STAT 404 Design of Experiments, UBC (2025) | Full factorial design with blocking, half-normal plot |
| [Predicting Airbnb prices in Budapest](airbnb-budapest-lasso) | STAT 301 Statistical Modelling, UBC (2025) | LASSO with cross-validated penalty, train/test evaluation |

Datasets are included only where their terms allow it; otherwise each README says where to download them.
